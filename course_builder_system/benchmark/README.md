# Benchmark Fixtures

This folder contains the FRM Phase 1 manual benchmark.

- `m1_s1/raw/` stores the original manual `.docx`, `.pptx`, and workbook inputs.
- `m1_s1/extracted/` stores extracted Markdown text from those manual assets.
- `m1_s1.gold.content_package.json` is the gold reference content package used
  by tests and evaluation helpers.

These files are large but intentional. They are benchmark fixtures, not runtime
outputs.
